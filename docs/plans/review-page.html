How the tabs fit together

One shared scope. Target chosen on New review decides what Changes shows; files checked in Changes feed the Files… target back on New review. Tabs are views of the same state, not separate pages. Running is the activity home. Live runs show progress + Stop. When a run finishes it stays exactly where it was — a Review completed status replaces the progress bar, and its findings render below. Nothing auto-archives, nothing moves. History (top-right) is the archive of older runs and the only way runs leave this tab. Changes is the preview and the picker. File list with per-file counts, inline syntax-highlighted diff, and checkboxes for picking files.

States

Running badge = active count only · Changes badge = current file count · completed runs show a green Review completed status in place · empty Changes (Whole project) shows a quiet "No diff for this target" · no runs yet shows an empty Running tab with "Start a review from New review" · a run with no issues shows a green ✓ status and "no issues", never an empty pane.
